# Snooker Practice

A personal project I built for my own use to practice snooker.

## About

This repository contains tools and notes I use to improve my snooker game —
things like practice routines, drills, and tracking my progress over time.

It is made primarily for myself, so it reflects my own training needs and
may not be polished for general use. Feel free to look around, borrow ideas,
or adapt anything here for your own practice.

## Goals

- Build consistent practice habits
- Work on cue ball control, potting accuracy, and break building
- Track progress and see what improves over time
